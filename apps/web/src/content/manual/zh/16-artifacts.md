# 产物与在线分享

Agent 每次运行产出的文件（网页、报告、数据文件、整个目录……）会作为 **产物（Artifacts）** 保存下来。除了下载，a2wave 还能把产物**一键变成在线分享链接**：对方点开链接就能直接预览网页、阅读报告，无需登录 a2wave、无需下载文件。

本章讲产物怎么分享、谁能看、看到的是什么。产物从哪来、保留多久，见 [运行记录](/wiki/runs)。

## 产物是什么

- **单文件**：网页（`.html`）、Markdown（`.md`）、以及其它任意文件。
- **目录化产物**：一个完整文件夹，常见于网页应用（含 `index.html` 及配套的 CSS / JS / 图片）。
- 产物在 [运行记录](/wiki/runs) 的产物列表里可以查看、**下载**、删除；目录可整体「下载为 ZIP」。

**谁能在产物列表里看到它**，规则与运行记录一致（见 [运行记录 → 可见范围](/wiki/runs)）：管理员看全部；Agent 的所有者和[协作成员](/wiki/members)看得到该 Agent 的全部产物，无论由谁、从哪个渠道触发；其他人只看得到自己触发的运行产出的产物。**删除比查看严格**：查看者只能删自己产出的产物，删别人的需要该 Agent 的所有者或编辑者权限。

> [!NOTE]
> 想让 Agent 专门产出可分享的网页，可在创建 Agent 时选 **网页应用生成器** 模板——它默认开启「需登录」的 7 天自动分享；创建后仍可在产物设置中调整。

## 开启自动分享

在 **Agent 详情页 → 产物** 标签页里配置。开启后，每次运行只要产出 html / md / 目录类产物，就会**自动创建分享链接**，并把链接附在运行消息和飞书通知里。

| 设置项 | 说明 |
|--------|------|
| **自动分享** | 总开关。关闭时产物只能下载、不生成在线链接。 |
| **访问权限** | 自动创建链接的默认访问级别：**需登录** 或 **公开**（见下）。 |
| **分享有效期** | 链接的有效天数，**1–365 天**，默认 **7 天**。过期后链接失效。 |

改完点 **保存**。

> [!IMPORTANT]
> **访问权限在「发布时」固化到链接上。** 这里的设置只对**之后新建**的分享生效，修改它**不会**改变已经发布出去的产物的访问权限。想收紧或放开某个已发出的链接，需要重新运行生成新的分享。

## 两种访问级别

- **需登录**（推荐默认）：访问者需要先通过企业 SSO 身份验证才能查看。适合内部、未最终确认的内容。
- **公开**：任何拿到链接的人都能直接查看，无需任何验证。适合确认无误、面向外部的内容。

建议先保持「需登录」，自己确认内容没问题后，再针对需要外发的场景改成「公开」。

## 访问者看到什么

访问者打开分享链接（形如 `…/s/…`）时：

- **需登录的链接**：会先跳转到登录页，用企业 SSO 身份验证，验证通过后自动回到分享内容。同一浏览器在一段时间内无需重复登录。
- **公开的链接**：直接展示内容。

内容呈现方式：

- **网页（HTML）**：在安全沙箱中原样渲染，对方像访问一个普通网页。
- **Markdown**：渲染成排版好的页面，并可查看原文。
- **目录化产物**：若包含 `index.html`，直接当作网页应用打开；否则展示一个文件清单页，可逐个浏览。
- **其它文件**：以下载形式提供。

## 通过飞书分发产物

把 Agent 发布到飞书后（见 [触发方式](/wiki/triggers)），在发布配置里可选 **通过文件发送产物**：

- **开启**：产物以**文件**形式直接发到飞书聊天里，方便对方保存。
- 即便以文件发送，只要该产物开启了自动分享，回复里**仍会附上「在线预览」链接**——对方不下载也能先点开看。
- **关闭**：产物以**下载链接**形式出现在回复文本中（若开了自动分享，同样附在线预览链接）。

## 产物可访问地址（管理员）

下载链接和分享链接里的域名/地址，取自 **设置 → 运行产物 → 用户可访问地址**：

- 填写访问者实际能访问到的基址，如 `https://a2wave.example.com`。留空时回退到请求头或 `localhost`。
- 本地调试用 **3501** 端口，线上运行使用 **3502** 端口。

> [!WARNING]
> 若这里填的是 `localhost` 或内网地址，外部（含飞书对端）将打不开链接。对外分享前请确认填的是对方可访问的地址。

## 排错思路

1. **链接打不开 / 报错** → 多半是「用户可访问地址」填成了本机地址，对方访问不到；改成对外可访问的基址。
2. **链接失效（找不到）** → 分享已过期、被删除，或产物随 worktree 清理被回收；重新运行生成新分享。详见 [运行记录](/wiki/runs) 的产物保留策略。
3. **改了访问权限对方仍打不开/仍能看** → 权限在发布时固化，旧链接不受影响；重新生成分享即可。
4. **飞书里只收到文件、没有预览链接** → 确认该 Agent 已开启「自动分享」。
