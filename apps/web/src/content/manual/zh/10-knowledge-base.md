# 知识库

知识库（Knowledge Base）是供 Agent 检索的文档集合。把企业内部资料、规范、FAQ 等沉淀为知识库文档并挂载到 Agent 后，Agent 即可在运行时检索这些内容辅助作答。

## 三种文档来源

| 来源 | 说明 | 关键字段 |
|------|------|---------|
| **upload** | 上传本地文件 | 原始文件名、类型、存储路径 |
| **feishu** | 从飞书云文档拉取 | 文档 token、类型（**docx / wiki**）、URL、飞书 App ID/Secret |
| **notion** | 从 Notion 页面拉取（转为 Markdown） | 页面 URL、Notion Integration Token |

飞书 / Notion 来源支持把已经维护在外部平台上的资料直接接入，避免重复维护。

### 接入 Notion 页面

1. 前往 [Notion Integrations](https://www.notion.so/my-integrations) 创建一个 **Internal Integration**，复制它的 Token。
2. 打开要同步的 Notion 页面，在右上角「•••」→「连接（Connections）」中添加该 Integration。
3. 在「知识库」新建文档，来源选「Notion 页面」，填入页面链接和 Token。

> [!NOTE]
> 仅同步页面自身内容（不含子页面，子页面会以占位符标注）；暂不支持数据库（database）链接。Notion 托管的图片和文件会以稳定占位符呈现，不保留会过期的临时下载链接。远程文档转换后的 Markdown 不能超过 10MB，超出时同步会失败并保留上一次成功内容。

## 管理文档

1. 进入「知识库」页面查看已有文档；点击任意文档卡片会弹出编辑弹窗。
2. 新建文档：点击「添加文档」，在弹窗里选择来源后一次添加多个：
   - **飞书 / Notion**：在链接框里**一行粘一个链接**，本批共用同一套凭证（飞书 App ID/Secret、Notion Integration Token）与同一段描述。
   - **本地文件**：点上传区后可**多选**文件。
3. 文档支持 **自动同步**（默认开，间隔默认 60 分钟），同步状态为 `idle / syncing / synced / error`，失败会记录原因；也可在文档弹窗里点「立即同步」手动拉取。

### 一次添加多个

每个链接、每个文件都会变成一个**独立的**知识库文档，各自同步、各自记录状态，也可以单独挂到不同 Agent 上。

**名称不用填**：远程文档取远端标题，上传文件取文件名。添加完成后，点开任意文档卡片就能改名。

> [!NOTE]
> 一次最多添加 10 个。远程文档要逐个抓取正文，数量太多会让你在弹窗前等太久；超过 10 个时提交会被拦下，请分批添加。

**部分失败不会连累其他**：平台逐条处理并实时显示进度，成功的立即入库，失败的会在结果区列出具体原因（例如「应用无该文档权限」）。失败的**链接**会保留在输入框里，改完直接重新提交即可；失败的**文件**需要重新选择。

### 更新 Notion 连接信息

1. 打开 Notion 来源的知识库文档编辑弹窗，找到「Notion 配置」。
2. 需要更换页面时修改「Notion 页面链接」；需要轮换凭证时填写新的 Integration Token。Token 输入框始终为空，留空保存会继续使用当前 Token。
3. 点击「保存」，再点击「立即同步」验证新页面或 Token 是否可用。

## 挂载与检索

在 Agent 配置中挂载知识库文档后，平台会在 **Run 启动时**把相关内容注入上下文，Agent 据此作答。知识库随文档更新而生效，适合承载「会变化、需要被引用」的资料。

## 与 Skill / 记忆的区别

- [知识库](/wiki/knowledge-base)：偏 **可检索的事实性资料**（规范、手册、FAQ）。
- [Skill](/wiki/skills)：偏 **能力与流程**。
- [长期记忆](/wiki/memory)：偏 **跨会话沉淀的偏好与历史**（平台自动维护）。

## 排错

| 症状 | 可能原因 | 解决 |
|------|---------|------|
| 飞书文档同步失败 | App 凭证/权限不足或文档类型不支持 | 确认 App ID/Secret 与文档为 docx/wiki |
| Notion 同步提示 Token 无效 | Integration Token 填错或已撤销 | 在 Notion Integrations 页面复制有效 Token，按「更新 Notion 连接信息」步骤在文档弹窗里替换并立即同步 |
| Notion 同步提示页面不存在 | 页面未共享给 Integration，或链接是数据库 | 在页面「•••」→「连接」中添加 Integration；数据库链接暂不支持 |
| Agent 没用到资料 | 未挂载或内容不相关 | 在 Agent 配置挂载对应文档 |
| 内容过期 | 未开自动同步 | 开启 autoSync 或手动同步 |
