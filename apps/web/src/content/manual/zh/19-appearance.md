# 外观与主题

a2wave 提供多套完整界面主题。主题是每位用户在当前浏览器中的个人偏好，不会改变管理员的全局设置，也不会影响其他用户。

## 切换主题

1. 点击侧边栏底部的用户头像。
2. 选择「外观与主题」。
3. 悬停主题卡片，或用键盘将焦点移到卡片上，即可实时预览。
4. 点击主题卡片选中它，再选择「应用主题」。

选择「取消」或关闭窗口会恢复打开选择器前的主题，不会保存预览。

## 主题一览

| 主题 | 外观 | 特点 |
|------|------|------|
| 跟随系统 | 自动 | 随设备浅色/深色外观在 Wave Light 与 Wave Dark 之间切换 |
| Wave Light | 浅色 | 温暖、克制，适合明亮环境 |
| Wave Dark | 深色 | 低眩光、高可读的默认深色工作台 |
| Neo Yellow | 浅色 | 暖纸背景、硬边框与醒目黄，编辑感更强 |
| Midnight | 深色 | 深海军蓝表面与清澈青色强调 |
| Forest | 深色 | 深橄榄与苔绿，适合长时间专注 |
| Graphite | 深色 | 近黑高对比表面、明确边界与黄色强调 |

## 跟随系统与持久化

「跟随系统」会即时响应操作系统的外观变化。选择的偏好保存在当前浏览器；刷新或重新打开 a2wave 后仍会生效。换一台设备或清除浏览器站点数据后，需要重新选择。

公共登录页面和首次初始化页面也会继续使用已保存的主题，使认证页面与工作台保持一致的外观。

在窄屏设备上，侧边栏会自动显示为紧凑图标栏，为主内容保留可用宽度；这不会覆盖你在桌面端保存的展开或收起偏好。

> [!TIP]
> 深色主题会同步调整表单、弹窗、表格、编辑器、Markdown 内容、运行日志和状态色，并非只更换强调色。

## 站点品牌（管理员）

主题是每个人自己的偏好，站点品牌则对所有人生效，在「设置 → 品牌外观」里统一配置，仅管理员可改：

| 配置项 | 作用 |
|--------|------|
| 网站副标题 | 显示在品牌标题下方 |
| 浏览器图标 | 浏览器标签页上的 favicon |

## 键盘操作

- 打开用户菜单后，可用 `Tab` 移动到「外观与主题」，按 `Enter` 打开。
- 选择器打开时会聚焦当前选项且不会改变主题；使用方向键在主题卡片间移动并预览或选中。
- 移动到「应用主题」并确认保存，或选择「取消」恢复原主题。
