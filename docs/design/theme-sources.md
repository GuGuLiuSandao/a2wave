# Theme Design Sources

The a2wave themes are original implementations built on the project's semantic token system. We
study public open-source products for interaction patterns and broad visual direction, but do not
copy their theme files, component code, icons, illustrations, or distinctive branded assets.

## References

| Reference | What we studied | What we did not copy |
|------|------|------|
| Vaultr Notes (`skoowoo/vaultr-notes`) | Editorial density, confident borders, warm paper surfaces, and high-visibility accents | Source code, exact palette values, layouts, icons, and assets |
| OpenCode | Developer-tool information hierarchy, tonal dark surfaces, and compact navigation | Theme files, exact color values, component code, and branding |
| Obsidian community themes | The value of complete, user-selectable appearance systems and readable Markdown/editor states | Individual theme packages, names, CSS, and bundled assets |

Neo Yellow is inspired by the broad editorial/neo-brutalist direction seen across modern
open-source tools. Its palette, semantic mapping, preview, radii, shadow scale, and component
treatment were designed specifically for a2wave.

No new third-party dependency or asset is introduced by the theme gallery. The existing licenses
and NOTICE inventory therefore require no update for this change.
